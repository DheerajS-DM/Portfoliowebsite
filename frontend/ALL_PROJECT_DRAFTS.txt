1. Why I built this:
- LLMs frequently hallucinate when verifying multi-step algebraic or calculus derivations.
- Pure Computer Algebra Systems (CAS) compute results, but they cannot verify whether Assertion A logically implies Assertion B in a formal proof step.
- I needed a system that decouples perceptual OCR from deterministic logic checking.

2. What I did:
- Decoupled Neuro-Symbolic Pipeline:

- Formal Verification with Z3 SMT Solver:
  Encoded mathematical assertions into First-Order Logic over Real Arithmetic. Proved validity between step A_i and step A_{i+1} by checking the unsatisfiability (UNSAT) of the negated implication: NOT (A_i IMPLIES A_{i+1}).

  Built a FastAPI backend streaming verification status step-by-step to an interactive React/Vite dashboard.

================================================================================

I built a userspace process resurrection engine and dynamic multi-tier priority scheduler in C to make compute-heavy workloads fault-tolerant with minimal memory overhead.

1. Why I built this:
- Full-heap checkpointing dumps entire gigabytes to disk on every snapshot, introducing massive I/O serialization latency.
- In long-running workloads, a crash shouldn't wipe hours of computation.
- I needed a low-overhead system to track only modified memory pages, capture hardware register states, and transparently resurrect crashed worker processes.

2. What I did:
- Incremental Dirty-Page Tracking (mprotect + SIGSEGV):
  Protected heap pages with PROT_READ using sigaltstack. When a worker writes to memory, the custom SIGSEGV handler captures the fault address (siginfo_t->si_addr), marks the dirty page in a 64-bit bitmap, upgrades the page to PROT_WRITE, and resumes execution.
- Register State Snapshotting (ucontext_t):
  Atomically serialized CPU register states (instruction pointer, stack pointer, registers) along with dirty pages into lean binary checkpoint files (.ckpt).
- Transparent Process Resurrection:
  A supervisor process uses non-blocking waitpid(). When a worker dies, it immediately spawns a replacement that mmaps the dirty pages, restores the ucontext_t registers, and resumes execution seamlessly.
- DPC-RR Dynamic Priority Scheduler:
  Implemented a 4-tier Round-Robin scheduler (Interactive, Compute, Batch, Idle) with priority aging algorithms to prevent thread starvation.
- POSIX Shared Memory Telemetry & Chaos Deck:
  Built lock-free ring buffers over POSIX shared memory (/dev/shm) to stream page faults and burst metrics to a PyQt6/PyQtGraph dashboard with real-time fault injection controls.

3. What could be improved:
- Thread-level isolation: Currently tracks single-threaded worker processes; multi-threaded support requires synchronizing pthread states and thread-local storage.
- Linux userfaultfd: Replacing mprotect/SIGSEGV with modern userfaultfd (UFFDIO_WRITEPROTECT) would eliminate signal-stack overhead.
- Copy-on-Write (CoW) snapshots: Using fork()-based background writes to avoid any micro-stalls during checkpoint serialization.
